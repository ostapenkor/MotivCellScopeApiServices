# МОТИВ — журнал аварий

Браузерное приложение: HTML + CSS + JavaScript, REST API на C#, MariaDB10.1. Нормализованная база, импорт реальной сводки с сохранением исходных строк, редактирование, роли, CSV и дашборд.

[Запуск, структура БД, импорт, API и объяснение кода](docs/journal/DATABASE.md) · [Проверки](docs/journal/TESTING.md)

```powershell
Copy-Item .env.case.example .env.case
# Задайте пароли и случайный JWT-ключ в .env.case.
docker compose --env-file .env.case -f docker-compose.case.yml -p motiv-case up -d --build
```

Откройте http://localhost:5090. Логины демо: admin, duty, engineer; пароль берётся из DEMO_PASSWORD вашей .env.case. Исходный Excel и локальные пароли не входят в репозиторий. Коллеги импортируют файл в свою базу командой из документации.

Остальные листы сводки сохраняются в архиве импорта для следующего этапа. Часовой пояс исходных дат неизвестен, поэтому они не объявляются UTC. А0/В не переводятся в 1–3 без подтверждения.

## Тренировочный профиль

Прежние KPI-контроллеры и root init.sql оставлены для тренировочного docker-compose.yml; case-профиль их не включает. Его база и том отделены от журнала.

## Макет мониторинга сети

Доработанная вкладка из HTML лиды: четыре региона, гексагональная карта, фильтры и список БС. Станции и аномалии демонстрационные. PHP-заглушка подготовлена; настоящее подключение C# REST ещё нужно реализовать.

**[Подробная инструкция запуска для коллеги](prototypes/monitoring/START-HERE.md)** · [Файлы макета](prototypes/monitoring). Для отдельного демо не нужны БД и .NET.
