# МОТИВ: API и PHP-сайт

Ветка `kolya-api-sync` создана от `main` (`aff0a9f`) под новую схему коллеги и MariaDB 10.1. Это отдельная версия для совместного просмотра; в `main` она автоматически не объединяется.

Сайт: **HTML + CSS + JS + PHP**. PHP синхронно получает JSON из **C# REST API**; напрямую к БД сайт не подключается. Весь сайт находится в одной папке `php-site/`. Новые действия API выполняются синхронно, а DTO запроса и ответа находятся рядом с действиями в файле контроллера.

- **[Как запустить](docs/START-HERE.md)** — Docker, настройка `.env`, порты, вход, обновление.
- **[Все методы REST API](docs/API.md)** — вход, поведение, выход и назначение; поля, фильтры, CSV, совместимые URL.
- **[Проверки](docs/TESTING.md)** — результаты и повторяемые HTTP-сценарии.
- **[PHP-сайт](php-site/README.md)** — устройство интерфейса и работа с API.
- **[OpenAPI](docs/openapi.json)** — машинный снимок контракта работающего API.

После настройки `.env` по инструкции запуск выполняется из корня репозитория:

```powershell
docker compose --env-file .env -f docker-compose.yml up -d --build
```

Открыть сайт: <http://127.0.0.1:5092/>; Swagger: <http://127.0.0.1:8080/swagger>. Используйте явно указанный compose-файл, чтобы не подключать старые настройки HTTPS Visual Studio.

## Что работает

Журнал аварий: 19 полей ТЗ, создание, просмотр, изменение, удаление, справочники, фильтры, пагинация и CSV. Отчёты: подробная выгрузка и групповые итоги. Дашборд и мониторинг: настоящие KPI, сетевые элементы, соты и аномалии из новой БД. Права проверяет API; PHP хранит JWT только в серверной сессии и защищает формы CSRF-токеном.

Карта пока остаётся явно обозначенной заглушкой. Раскрытие точных координат отключено по умолчанию и вынесено на обсуждение. Измерения доступности в этой схеме нет: API возвращает неизвестное значение, а активность трафика показывает отдельно. Схема БД, авторизация и административный контроллер коллеги не изменены. Пароли существующих пользователей нужно получить у автора авторизации.

## Где находится код

```text
php-site/                              весь PHP-сайт, HTML, CSS и JS
MotivCellScopeApiServices/
  Controllers/IncidentsController.cs    аварии, DTO, валидация, CSV
  Controllers/ReportsController.cs      отчёты и их DTO
  Controllers/MonitoringController.cs   мониторинг и его DTO
  Controllers/ReferenceController.cs    справочники, health, ошибки
  Controllers/AuthController.cs        существующая авторизация коллеги
  Controllers/AdminController.cs       существующие процедуры коллеги
init.sql                               исходная новая схема и данные
docker-compose.yml                     MariaDB 10.1 + API + PHP
docs/                                  запуск, API, результаты проверок
tests/api_smoke.py                      HTTP-проверка API
tests/php_flow.py                       PHP → API, формы и права
```

`init.sql` из корня выполняется только при первом запуске пустого тома. Старая MariaDB 11 и новая MariaDB 10.1 используют разные тома; повторный запуск не является миграцией схемы.
